# IoT Lab

A visual learning playground with 20 experiments and 10 practice questions about IoT devices. Most concepts take one or two clicks to explore.

## Website

The app lives in `dist/` and needs no build step, backend, API key, or account. Serve it locally with:

```sh
python3 -m http.server 5173 --directory dist
```

GitHub Actions publishes `dist/` to GitHub Pages on pushes to `main`.

## Teaching content

Teacher notes contain source links and corrections to the lesson slides. Numerical values and animations are illustrative teaching models, not hardware benchmarks. Student progress stays in browser local storage. Quiz answers support informal practice; learning impact has not been measured.

## Assets

Plant and wearable illustrations were generated for the lesson and are representative designs. Raspberry Pi 5 and RP2040 photographs come from Raspberry Pi's official product pages, linked in the app. Icons are from Phosphor Icons. Fonts are DM Sans and Manrope via Google Fonts.
